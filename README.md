**Projeto Currículo**

O Projeto Currículo consiste no desenvolvimento de uma página web para apresentar informações pessoais e profissionais de forma organizada. A finalidade é criar um currículo digital que possa ser acessado por meio de um navegador.

A página utiliza HTML para estruturar o conteúdo, CSS para definir a aparência e a organização visual e imagens como parte da apresentação. O projeto também foi publicado utilizando o GitHub Pages, permitindo seu acesso pela internet.

**Principais recursos:** estruturação de informações em uma página web, estilização visual, utilização de imagens e publicação do projeto na web.

**Tecnologias utilizadas:** HTML e CSS.
